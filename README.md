# Code and data related to Erdos problem 1045

This folder contains the computer programs for computations involved in the project on Erdos problem 1045.

Results are written in:
*On the maximum product of diagonal lengths of diameter 2 point sets.* 
Stijn Cambie, Arne Decadt, Yanni Dong, Tao Hu and Quanyu Tang.
(to appear on Arxiv this month)
